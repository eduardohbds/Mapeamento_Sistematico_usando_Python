# MAPEAMENTO SISTEMÁTICO USANDO PYTHON 

Esse projeto tem como intuito auxiliar em vários momentos do trabalho de mapeamento sistemático. Foram baseados nos trabalhos de [Syriani et al.](https://doi.org/10.1016/j.cola.2024.101287) e [Teperikidis et al.](https://doi.org/10.23736/S2724-5683.24.06568-2), e modificados para serem usados no [Google Colab](https://colab.research.google.com) e usa como linguagem de programação o Python.

As etapas que eu implementei por razões de organização estão separadas cada uma em suas pastas. Coloquei cada código no formato notebook ou .ipynb. 

Instalação dos pacotes necessários para execução esta localizado em uma célula em cada notebook.

Alem disso é necessário que você crie uma conta no OpenApi para executar os códigos.

Uma alternativa para o Google Colab Web é a extensão do [Colab](https://marketplace.visualstudio.com/items?itemName=Google.colab) que pode ser usada junto com a IDE [VSCode](https://code-visualstudio-com.translate.goog/)
